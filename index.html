    PHILIPPINES · CODE CONTEXT

    Items to verify before you draw.

    REFERENCE ONLY

    Use current, locally adopted regulations and project-specific requirements for final dimensions. These references are a starting point for coordination, not a substitute for code review or professional design.

    §

    BUILDING RULES

    National Building Code

    • Confirm occupancy classification and allowable room use.
    • Check light, ventilation, exit access, and required clear widths.
    • Verify the current local adoption and amendments.
    DPWH laws and codes ↗
    ♿

    ACCESSIBILITY

    BP 344 and IRR

    • Review accessible routes, door clearances, ramps, and turning space.
    • Coordinate accessible facilities and signage where required.
    • Use the current implementing rules for the project.
    NCDA · BP 344 ↗
    🔥

    FIRE CODE

    RA 9514 · Fire Code of the Philippines

    • Classify the occupancy and compute occupant load.
    • Check exits, travel distance, fire separations and protection systems.
    • Secure the Fire Safety Evaluation Clearance before the building permit.
    Bureau of Fire Protection ↗
    ▦

    STRUCTURAL

    NSCP 2015 · Structural Code

    • Design loads, seismic and wind per Volume 1.
    • Concrete, steel and masonry member design.
    • Structural plans must be signed by a licensed civil engineer.
    ASEP publication
    ⚡

    ELECTRICAL

    PEC 2017 · Electrical Code

    • Branch circuits, outlet spacing and wet-area protection.
    • Panel board location and clearances.
    • Plans signed by a Professional Electrical Engineer.
    IIEE publication
    ◌

    PLUMBING

    National Plumbing Code

    • Fixture counts by occupancy.
    • Drainage, venting and septic tank requirements.
    • Water supply sizing and fixture rough-ins.
    RA 1378 · Revised NPC
    ♻

    SUSTAINABILITY

    Philippine Green Building Code

    • Energy efficiency, water efficiency and materials.
    • Applies to buildings above the size thresholds in the code.
    • Referral code of PD 1096.
    DPWH references ↗
    ⌖

    ZONING

    Local zoning ordinance

    • Allowed use, height limits and floor-area ratio.
    • Setbacks and parking requirements beyond the NBC.
    • Locational clearance comes before the building permit.
    City / municipal planning office
